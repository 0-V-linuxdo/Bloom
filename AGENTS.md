# Bloom++

Plugin host for chatgpt.com. Architecture follows Void++ (`definePlugin`, PluginManager, SettingsStore, Bun/Node userscript build) without Grok turbopack.

- Brand: **Bloom++**. Repo: `Bloom`. Package: `bloompp`. Global: `window.Bloom`. CSS: `bloom-`.
- Do not put `ChatGPT` in the product/repo/package name. `@match` may still target chatgpt.com.
- v1 plugins: ChatStateFavicons, InputHistory, NoShareLink, NoDictation, required `_core/settings` (sidebar rail row + in-flow panel, no FAB).
- NoShareLink / NoDictation are CSS-only (`registerStyle`). Do not add documentElement MutationObservers or `querySelectorAll("button")` scans. Do not use wrapper `:has()`.
- `registerStyle` queues `<style>` in memory. `flushStyles()` appends to `document.head` at HostReady. Never observe `document.documentElement`. Never append a `<style>` to `document.documentElement` — extra children under `<html>` break ChatGPT React hydration (blank page, dead clicks).
- Never append `#bloom-root`, the InputHistory HUD, or any other host node to `document.documentElement`. Mount on `document.body` only, and only after React internals exist on `document` / `html` / `body`. `#bloom-root` is a **zero-size** HUD host: `position:fixed; top:0; left:0; width:0; height:0; overflow:hidden; pointer-events:none`. Never `inset:0`. Never a FAB. Never a settings overlay. Settings pin a persistent `Bloom++` row as the **previous sibling** of the account footer that contains `[data-testid="accounts-profile-button"]` (`nav.nextElementSibling` or `.sticky.bottom-0` itself — never a child of that sticky box). Plugin rows live in an in-flow panel above that row. `GM_registerMenuCommand` **always paints** the same panel (toggle if it exists); never `profile.click()` as the primary path. Last-resort dock is a left-rail-width box on `document.body`, not a viewport overlay. InputHistory HUD mounts on `document.body`.
- HostReady waits for `document.body` (poll + DCL, no html observer), then until React host internals appear, with an 8s **ceiling** (not a minimum). HostShell (rail pin) fires as soon as `#stage-slideover-sidebar` or the profile chip exists — do not wait for two `requestIdleCallback` turns. After the island gate + idle, auto-start HostReady plugins (`requestChromeReady`). Settings must not call `requestChromeReady` on click. Never `popover` / `showPopover` / `popover="auto"` / `<dialog>.showModal()` / `role="dialog"` / `aria-modal` / `body.inert` / window `resize` writing layout / window capture `pointerdown`. Account-menu injection (bonus menuitem) uses bubble `click` on `document` (no capture, no preventDefault on the profile click). `visible()` must not blanket-reject `[role="dialog"]` — allow the small account switcher (Settings / Log out text) and exclude the large Settings window with tabs. `findProfileButton` prefers the on-screen left-third chip (width/height > 0, `left >= 0`) and must not require `getClientRects().length` alone. Observe nothing on `document.documentElement`. Do not observe `document.body` with `subtree` (sidebar-host childList is OK). Gear swaps an in-panel view. `watchHostScheme` uses focus / visibility / matchMedia. If the island gate fails, still fire HostShell **and** HostReady (default-on plugins must not stay dead). Dual instance must not silent-skip: replace `window.Bloom` and init. ChatStateFavicons must not observe `document.body` with `subtree` (composer-root childList is OK). InputHistory must use `StartAt.HostReady` and capture-phase keydown.
- ChatStateFavicons starts at `DOMContentLoaded` (head only). Own `#bloom-chat-state-favicon` as the **last** `link[rel=icon]` in `document.head`. Head-only guard with `subtree` so child `href` edits are visible. Always compose a **white** blossom (PNG 32×32, no SMIL, no official href as a base). Halo stroke for contrast on pale tabs; `bg` may use a plate. Restore official only on `stop()`.
- NoDictation hides Dictation (`Start dictation` / `Dictate button` / 听写), never `composer-speech-button` (Voice).
- Userscript `@updateURL` / `@downloadURL` / `@icon` must be GitHub raw (`https://raw.githubusercontent.com/0-V-linuxdo/Bloom/main/...`), same as Void++. `max-age=300`. Never jsDelivr `@heads/main` (7-day cache; purge does not stick). Never `github.com/.../raw/refs/heads/...` (returns HTML, Tampermonkey / Violentmonkey cannot update from it).
- Userscript-only. License GPL-3.0-or-later.
- ChatGPT detectors stay in `src/host` + plugin `detect.ts`. Do not `@require` Chat-State-Favicons core.
