# Bloom++

Plugin host for chatgpt.com. Architecture follows Void++ (`definePlugin`, PluginManager, SettingsStore, Bun/Node userscript build) without Grok turbopack.

- Brand: **Bloom++**. Repo: `Bloom`. Package: `bloompp`. Global: `window.Bloom`. CSS: `bloom-`.
- Do not put `ChatGPT` in the product/repo/package name. `@match` may still target chatgpt.com.
- v1 plugins: ChatStateFavicons, InputHistory, NoShareLink, NoDictation, required `_core/settings` (floating button).
- NoShareLink / NoDictation are CSS-only (`registerStyle`). Do not add documentElement MutationObservers or `querySelectorAll("button")` scans. Do not use wrapper `:has()`.
- `registerStyle` queues `<style>` in memory. `flushStyles()` appends to `document.head` at HostReady. Never observe `document.documentElement`. Never append a `<style>` to `document.documentElement` — extra children under `<html>` break ChatGPT React hydration (blank page, dead clicks).
- Never append `#bloom-root`, the InputHistory HUD, or any other host node to `document.documentElement`. Mount on `document.body` only, and only after React internals exist on `document` / `html` / `body`. `#bloom-root` is a **zero-size** `position:fixed; width:0; height:0; overflow:visible; pointer-events:none` host — reset those inline styles on every `ensureHost()`. Never let it participate in `body > div` layout. The FAB is `pointer-events: auto`.
- HostReady waits for `document.body` (poll + DCL, no html observer), then until React host internals appear, with an 8s **ceiling** (not a minimum). After the island gate + idle, auto-start HostReady plugins (`requestChromeReady`). The blossom only toggles the prebuilt **non-modal settings flyout** — it must not call `requestChromeReady` or rebuild the panel on click. Settings is a ~520px flyout next to the FAB (cap 560px, never `vw-24` full-bleed, never docked to the left-rail profile): never a full-viewport backdrop `<button>`, never `aria-modal="true"`, never `panel.focus()`, never `body.inert` / `overflow:hidden`, never `popover="auto"` (light-dismiss swallows the underlying click). Closed = `display:none` + `inert` + `aria-hidden` + `pointer-events:none`. Outside dismiss: bind window capture `pointerdown` **only while open**, `composedPath()`, and must **not** `preventDefault` / `stopPropagation`. Unbind on close. Esc on `window` only while open. `z-index` ~ 10000, not INT32_MAX. Gear swaps an in-panel view. `watchHostScheme` uses focus / visibility / matchMedia — never a `document.documentElement` observer. If the island gate fails, still fire HostShell (FAB) and skip HostReady. ChatStateFavicons must not observe `document.body` with `subtree` (composer-root childList is OK). Do not treat `DOMContentLoaded` or `window` `load` as hydrated for `#bloom-root`. InputHistory must use `StartAt.HostReady` and capture-phase keydown.
- ChatStateFavicons starts at `DOMContentLoaded` (head only). Own `#bloom-chat-state-favicon` as the **last** `link[rel=icon]` in `document.head`. Head-only guard with `subtree` so child `href` edits are visible. Always compose a **white** blossom (PNG 32×32, no SMIL, no official href as a base). Halo stroke for contrast on pale tabs; `bg` may use a plate. Restore official only on `stop()`.
- NoDictation hides Dictation (`Start dictation` / `Dictate button` / 听写), never `composer-speech-button` (Voice).
- Userscript `@updateURL` / `@downloadURL` / `@icon` must be GitHub raw (`https://raw.githubusercontent.com/0-V-linuxdo/Bloom/main/...`), same as Void++. `max-age=300`. Never jsDelivr `@heads/main` (7-day cache; purge does not stick). Never `github.com/.../raw/refs/heads/...` (returns HTML, Tampermonkey / Violentmonkey cannot update from it).
- Userscript-only. License GPL-3.0-or-later.
- ChatGPT detectors stay in `src/host` + plugin `detect.ts`. Do not `@require` Chat-State-Favicons core.
