# Bloom++

Plugin host for chatgpt.com. Architecture follows Void++ (`definePlugin`, PluginManager, SettingsStore, Bun/Node userscript build) without Grok turbopack.

**先拉取 GitHub 上的最新版，再修改。** GitHub `main` (`https://github.com/0-V-linuxdo/Bloom`) is the source of truth. Before any code change: clone/pull `main`, then patch that snapshot. Never rsync or copy a stale sandbox tree over `main` — that is how 1.4.8 wiped the 1.4.7 settings panel. Diff against GitHub HEAD, then edit. Do not bump `@version` until after that pull (Tampermonkey will not downgrade).

- Brand: **Bloom++**. Repo: `Bloom`. Package: `bloompp`. Global: `window.Bloom`. CSS: `bloom-`.
- Do not put `ChatGPT` in the product/repo/package name. `@match` may still target chatgpt.com.
- v1 plugins: ChatStateFavicons, InputHistory, NoShareLink, NoDictation, NoSidebarIdentity, RecentTopics, Cleaner, required `_core/settings` (sidebar rail row in the exporter pocket + body-docked panel, no FAB). Plugin list in that panel is a Void++ BaseCard stack (icon tile, 2-line description, author footer, gear + switch) — not compact 36px rows.
- NoShareLink / NoDictation / NoSidebarIdentity / Cleaner are CSS-only (`registerStyle`). Do not add documentElement MutationObservers or `querySelectorAll("button")` scans. Do not use wrapper `:has()`. NoSidebarIdentity hides the account-chip display name with `visibility:hidden` (keep the text slot next to the avatar). Never `display:none` the `.min-w-0` text column — that collapses the chip to the avatar. Never hide the avatar or `#bloom-rail-item`. Cleaner hides the Download-apps CTA (`a[href*="/download"]` / `download-app-button`) and the composer “can make mistakes” notice (`[data-testid="thread-disclaimer"]` / `[class*="--vt-disclaimer"]` inside `#thread-bottom-container`). Never hide the whole `#thread-bottom-container` (that would take the composer with it). `display:none` is OK for those two — they should leave the layout. Toggles `hideDownloadApps` and `hideDisclaimer`.
- RecentTopics is a Ctrl+` switcher. HUD `#bloom-rt-host` mounts on `document.body` (not `document.documentElement`). No `popover` / `inset:0` overlay / `role="dialog"`. Visit list comes from pathname + Recents `a[href^="/c/"]` + current-turn DOM; do not poll `/backend-api/conversations`.
- `registerStyle` queues `<style>` in memory. `flushStyles()` appends to `document.head` at HostReady. Never observe `document.documentElement`. Never append a `<style>` to `document.documentElement` — extra children under `<html>` break ChatGPT React hydration (blank page, dead clicks).
- Never append `#bloom-root`, the InputHistory HUD, RecentTopics `#bloom-rt-host`, or any other host node to `document.documentElement`. Mount on `document.body` only, and only after React internals exist on `document` / `html` / `body`. `#bloom-root` is a **zero-size** HUD host: `position:fixed; top:0; left:0; width:0; height:0; overflow:hidden; pointer-events:none`. Never `inset:0`. Never a FAB. Never a settings overlay. Settings pin a persistent `Bloom++` row as the **previous sibling of the avatar chip** (or its single-child wrapper) **inside** the account footer — chatgpt-exporter pocket. Never a direct child of `nav` / `#stage-slideover-sidebar` (React #418 hydration wipe). Collapsed rail may pin to `#stage-sidebar-tiny-bar`. Plugin cards live in a **body-docked** panel (`document.body` + `.bloom-rail-dock`, `z-index:10000`). Never `rail.before(panel)` / never in-flow inside the footer (inflates the React shell and freezes long chats). `GM_registerMenuCommand` **always paints** the same body-docked panel; never `profile.click()` as the primary path. The dock is a left-rail-width box on `document.body`, not a viewport overlay. `pinRail` never mounts or moves the panel. `watchSidebar` only restores `#bloom-rail-item` (disconnect before mutate). InputHistory HUD and RecentTopics panel mount on `document.body`.
- HostReady waits for `document.body` (poll + DCL, no html observer), then until React host internals appear, with an 8s **ceiling** (not a minimum). HostShell may fire when `#stage-slideover-sidebar` exists, but **Settings pin waits for HostReady** (do not mutate `nav` mid-hydration). After the island gate + idle, auto-start HostReady plugins (`requestChromeReady`). Settings must not call `requestChromeReady` on click. `openSettings` must not wait on `whenShellReady`. Never `popover` / `showPopover` / `popover="auto"` / `<dialog>.showModal()` / `role="dialog"` / `aria-modal` / `body.inert` / window `resize` writing layout / window capture `pointerdown`. Account-menu injection (bonus menuitem) uses bubble `click` on `document` (no capture, no preventDefault on the profile click). `visible()` must not blanket-reject `[role="dialog"]` — allow the small account switcher (Settings / Log out text) and exclude the large Settings window with tabs. `findProfileButton` returns only the on-screen left-third chip (`width > 40`, `height > 16`, `left >= 0`) and **must not** fall back to an off-screen `hits[0]`. Observe nothing on `document.documentElement`. Do not observe `document.body` with `subtree` (footer-pocket childList without subtree is OK). Gear swaps an in-panel view. `watchHostScheme` uses focus / visibility / matchMedia. If the island gate fails, still fire HostShell **and** HostReady (default-on plugins must not stay dead). Dual instance must not silent-skip: replace `window.Bloom` and init. ChatStateFavicons must not observe `document.body` with `subtree` (composer-root childList is OK). InputHistory must use `StartAt.HostReady` and capture-phase keydown.
- ChatStateFavicons starts at `DOMContentLoaded` (head only). Own `#bloom-chat-state-favicon` as the **last** `link[rel=icon]` in `document.head`. Head-only guard with `subtree` so child `href` edits are visible. Always compose a **white** blossom (PNG 32×32, no SMIL, no official href as a base). Halo stroke for contrast on pale tabs; `bg` may use a plate. Restore official only on `stop()`.
- NoDictation hides Dictation (`Start dictation` / `Dictate button` / 听写), never `composer-speech-button` (Voice).
- Userscript `@updateURL` / `@downloadURL` / `@icon` must be GitHub raw (`https://raw.githubusercontent.com/0-V-linuxdo/Bloom/main/...`), same as Void++. `max-age=300`. Never jsDelivr `@heads/main` (7-day cache; purge does not stick). Never `github.com/.../raw/refs/heads/...` (returns HTML, Tampermonkey / Violentmonkey cannot update from it).
- Userscript `@version` must be strictly greater than the last published GitHub `main` version (`package.json` + `src/utils/constants.ts` + rebuilt header). Tampermonkey / Violentmonkey will not downgrade (1.4.6 cannot replace 1.4.7). Date prefix `[YYYYMMDD]` is display-only when the date is equal; comparison still uses `vX.Y.Z`.
- Userscript-only. License GPL-3.0-or-later.
- ChatGPT detectors stay in `src/host` + plugin `detect.ts`. Do not `@require` Chat-State-Favicons core.
